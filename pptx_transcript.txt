Detection Gap
Signature IDS: high precision on known threats but zero recall on zero-days.
ML-only models: broad generalization but unacceptable false-positive rates.
Edge Deployment Gap
Most hybrid IDS research targets cloud infrastructure. IoT requires edge-local processing for latency, bandwidth, and data privacy constraints.
Operational Resilience Gap
Deployed ML models degrade silently as traffic distributions evolve. No existing IoT IDS integrates MLOps drift detection with automated retraining.
Our Solution: Containerised Hybrid IDS on Raspberry Pi 4 ΓÇö combining Zeek/Suricata + Isolation Forest Ensemble + XGBoost + Formal Score Fusion + MLOps Drift Monitoring

Machine Learning ΓÇö Isolation Forest Formulation
Mathematical Foundation
Anomaly Score
s(x, n)  =  2^[ -E[h(x)] / c(n) ]
Score ΓåÆ 1.0 means anomalous
Path Length Normaliser
c(n)  =  2H(nΓêÆ1) ΓêÆ 2(nΓêÆ1)/n
Average BST search length
Harmonic Approx.
H(i)  Γëê  ln(i) + 0.5772
EulerΓÇôMascheroni constant
Anomalies are Rare
Few instances, statistically different from normal behaviour ΓÇö isolated by fewer random binary partitions.
Short Path = Anomaly
Anomalous flows reach leaf nodes in 2ΓÇô4 splits. Normal flows require 8ΓÇô15 splits. Score normalised to [0,1].
O(n log ╧ê) Complexity
Subsampled trees of size ╧ê give O(t┬╖n┬╖log ╧ê) time complexity. Suitable for ARM edge hardware at 1.8 GHz.
No Labels Required
Fully unsupervised ΓÇö detects zero-day threats without any labelled attack examples. Essential for IoT deployment.

Adversarial evasion: attacker aware of ╬▒=0.25 could craft flows to evade IF boundary
Small-scale LAN (10 IoT devices) ΓÇö larger multi-vendor deployments may differ
Labelled retraining required as novel attack families emerge for XGBoost model
Static 5-tuple flow key ΓÇö application-layer context not captured
