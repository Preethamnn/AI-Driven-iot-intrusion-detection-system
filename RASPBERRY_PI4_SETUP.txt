SECTION 4: NETWORK CONFIGURATION ON RASPBERRY PI
----------------------------------------------------------------

  # Set static IP on eth0 for camera network
  sudo nano /etc/dhcpcd.conf

  # Add at the bottom:
  interface eth0
  static ip_address=192.168.1.100/24
  static routers=
  static domain_name_servers=8.8.8.8

  # Save (Ctrl+X, Y, Enter) and restart
  sudo systemctl restart dhcpcd

  # Verify
  ip addr show eth0
  # Should show 192.168.1.100

  # Test camera is reachable
  ping 192.168.1.64

SECTION 5: EDGE GATEWAY CONFIGURATION
----------------------------------------------------------------

  # Edit config on Pi
  nano /home/pi/New-IoT-Project/config/edge-gateway.yml

  # Set these values:
  edge_gateway:
    packet_capture:
      interface: eth0
      buffer_size_mb: 64
      capture_filter: ""
    forwarding:
      upstream_endpoints:
        - "http://YOUR_PC_IP:8000/api/v1/ingest"
      batch_size: 100
      flush_interval_ms: 5000
      retry_attempts: 3

  # Find YOUR_PC_IP: run ipconfig on Windows
  # Look for WiFi adapter IPv4 address (e.g., 10.80.47.82)

----------------------------------------------------------------
SECTION 9: TROUBLESHOOTING
----------------------------------------------------------------

Cannot SSH into Pi:
  - Check Pi IP: arp -a on your PC
  - Ensure Pi is on same WiFi

Scapy "No such device eth0":
  - Run: ip link show
  - Use correct interface name

Permission denied for capture:
  - Run with sudo
  - Or: sudo setcap cap_net_raw+eip /usr/bin/python3

Camera not reachable (ping fails):
  - Check camera label for default IP
  - Common Sparsh defaults: 192.168.1.64 or 192.168.1.100
  - Ensure Pi eth0 is on same subnet (192.168.1.x)

Packets not forwarded to PC:
  - Check PC firewall allows port 8000
  - Verify AI service: docker ps
  - Check upstream URL matches PC's WiFi IP
